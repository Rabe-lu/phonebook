Телефонный справочник (CLI)
Консольное приложение для управления контактами.

🚀 Запуск приложения

python main.py

Возможности:
- Просмотр всех контактов
- Добавление нового контакта
- Поиск контактов по строке
- Редактирование контакта
- Удаление контакта
- Сохранение данных в JSON


ТЕСТЫ
Тесты реализованы в модели tests/test_func.py
Запуск тестов с описанием командой:

pytest -vv

Покрыты тестами:
- добавление контакта
- изменение контакта
- удаление контакта
- поиск контактов
- чтение JSON-файлов
